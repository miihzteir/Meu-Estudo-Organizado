# Meu Estudo Organizado

Aplicativo original completo, com Agenda mensal, Pomodoro, Progresso, matérias, PDFs, resumos, flashcards, links e sincronização pelo Firebase/Google.

## Publicação automática no GitHub Pages

1. Extraia o ZIP e envie todo o conteúdo para a raiz do repositório `Meu-Estudo-Organizado`.
2. Abra **Settings > Pages** no GitHub.
3. Em **Build and deployment > Source**, escolha **GitHub Actions**.
4. Abra a aba **Actions** e aguarde a tarefa `Publicar Meu Estudo Organizado` ficar verde.

Depois disso, toda atualização enviada ao GitHub será publicada automaticamente.
